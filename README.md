# 📖 Sobre

O **The Blog** é uma aplicação Full Stack moderna desenvolvida com **Next.js App
Router**, oferecendo uma experiência intuitiva tanto para leitores quanto para
administradores.

O projeto foi desenvolvido seguindo princípios modernos de arquitetura
Front-end, com foco em:

* Interface limpa
* Desempenho
* Design responsivo
* Reutilização de componentes
* Estrutura escalável
* Otimização para SEO

A plataforma inclui um blog público completo e um painel administrativo para
gerenciamento de conteúdo.

# 📂 Estrutura do Projeto

### 📂 Estrutura do Projeto

```text
src/
├── actions/          # Server Actions (Autenticação, Posts e Upload)
├── app/              # Rotas e páginas do Next.js (App Router)
│   ├── admin/        # Painel administrativo (Auth, Criação/Edição de posts)
│   └── post/         # Visualização pública das postagens
├── components/       # Componentes da interface (UI, Formulários, Admin)
├── db/               # Configuração do Drizzle ORM, schemas e migrations
├── dto/              # Objetos de Transferência de Dados (DTOs)
├── lib/              # Regras de negócio, consultas e validações
├── models/           # Definições de modelos de dados
├── repositories/     # Camada de repositório de dados (Drizzle e JSON)
└── utils/            # Funções utilitárias e helpers
```

# 🚀 Primeiros Passos

Clone o repositório

```bash
git clone https://github.com/joaogabriel-11/the-blog-next-react.git
```

Acesse a pasta do projeto

```bash
cd the-blog-next-react
```

Instale as dependências

```bash
npm install
```

Execute o projeto

```bash
npm run dev
```

Abra

```
http://localhost:3000
```
